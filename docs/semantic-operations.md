# 意味付き操作とパラメーター

「右前腕を右回り30度、平均30度/秒でひねる」のように、操作の意味と数値を一緒に管理する。保存版には、生成済みの曲線と生成時の操作ID・定義版・パラメーターを残す。生成した部品は既存の `knowledge-inspect → derive` で中間動作、さらに上位の表現へ組み込める。

## 画面で使う

モーション → 身体・意味・部品の知識 → **意味付きパラメーターから作る・編集する** を開く。操作、対象の左右、方向、角度、片道時間または平均角速度、保持時間、元へ戻るかを指定し、試演または「部品として保存」を選ぶ。保存した動作を選び直すと生成時の値が入る。数値を変えて保存すると別IDの候補を作り、元の動作は保持する。

開始姿勢は既定で休息姿勢。保存動作を選択して開始姿勢のチェックを付けると、その固定版の終点を使う。APIは固定版の任意の時刻を指定でき、保存済みの値を編集する場合は元の時刻を保持する。指定するのは動かす部位の開始姿勢で、他の部位は合成側で受け持つ。

曲線を直接編集した場合、意味付きパラメーターは**生成時の記録**として残る。意味付き画面での試演・保存はその数値からの再生成であり、後から加えた曲線編集を再現する操作ではない。

## 操作の意味

| ID（すべて定義版1） | 操作 | 方向 | 最大変位 |
|---|---|---|---|
| forearm-twist | 前腕をひねる | 肘から手先を見る右回り／左回り | 75度 |
| upper-arm-twist | 上腕をひねる | 肩から肘を見る右回り／左回り | 60度 |
| elbow-bend | 肘を曲げ伸ばしする | 開始姿勢から曲げる／伸ばす | 90度 |
| head-turn | 顔を左右へ向ける | キャラクター自身の右／左 | 60度 |
| head-nod | 頭を上下に動かす | 下げる／上げる | 30度 |
| torso-turn | 体幹をひねる | キャラクター自身の右／左 | 40度 |

腕の `side` は動かす腕。ひねりの `direction` は腕の軸を根元から先へ見た回転方向で、画面の左右とは別。頭・体幹の角度は、定義にある骨への配分の合計。これらは同梱VRM・固定立位向けの制作上の定義で、解剖学的な関節限界や任意姿勢での厳密な視線方位を表すものではない。

角度は開始姿勢からの変位。時間は片道0.25〜10秒。平均角速度は1〜180度/秒で、`角度÷平均角速度` が片道時間になる。開始と到達で滑らかに加減速するため、瞬間速度は一定ではない。保持0〜10秒、戻りも片道と同じ時間を使う。組み合わせた姿勢・軌道が既存の座標範囲を超えれば候補生成を拒否する。

## エージェント・API

1. `semantic-search {query}`：関連する操作の `key`（`operation:ID@1`）と説明だけを取得。
2. `semantic-inspect {id,version:1}`：方向基準、単位、範囲、既定値、入力仕様を必要な時に取得。
3. `semantic-build`：以下のように指定し、未保存の通常クリップを生成。

```json
{
  "id": "forearm-twist",
  "version": 1,
  "name": "右前腕を30度ひねって戻す",
  "parameters": {
    "side": "right",
    "direction": "clockwise",
    "angleDeg": 30,
    "timing": {"mode": "speed", "speedDegPerSec": 30},
    "holdSec": 0.3,
    "returnToStart": true
  }
}
```

この例は片道1秒＋保持0.3秒＋戻り1秒の2.3秒。ライブ再生は必要に応じ現在状態からの接続時間が加わる。時間で指定する場合は `timing: {mode:"duration",durationSec:1}`。開始姿勢を変える場合はトップレベルに `base: {ref:{id,version},time}` を付ける。

HTTP・MCP・CLIでは生成結果の `motion` を通常の `play / save` へ渡す。会話内ではホストが要求ごとの一時領域へ保存し `draftKey / ref / revision / parameters` を返す。inspectで確かめた生成部品はderiveに再利用できる。最終候補と必要な中間部品だけを一括保存し、未採用の案は残さない。開始姿勢に別の生成部品を使った場合も依存する固定版を保存する。人の採用評価は別途行う。
