# 公開対象

このリポジトリはPrometheus V3のソースコード、テスト、手付けの動作例、設計・操作資料を収録しています。旧版のGit履歴は取り込んでいません。

以下は公開対象から除外しています。

- 会話履歴、SQLiteデータベース、実行ログ、ローカル検証のJSON記録。
- 個人用Tailscaleアドレスと実環境のアクセス設定。代わりに空の設定例を収録。
- VRMモデル、テクスチャを含むモデルデータ、取得済みの第三者モーションデータセット。
- 画面キャプチャやUI提案画像、依存パッケージ本体、ビルド生成物、キャッシュ。

公開用コピーで、秘密鍵・既知のトークン形式・個人メール・ローカルユーザーパス・個人用ホスト名を点検しました。テスト内の架空ホスト名と開発用loopbackアドレスは残しています。

実際のアクセス設定は `config/access.example.json` を `config/access.json` にコピーして編集してください。後者はGit管理しません。モデルの配置は [モデルの説明](../models/README.md) を参照してください。
