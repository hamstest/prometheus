# 検証

Node.js 24以上で `npm ci`、`npm run build`、`npm test` を実行します。

実モデルを使うテストには [基準モデル](../models/README.md) を別途配置してください。テストは軌道の連続性、保存版の不変性、競合、HTTP/stdio境界、実VRMの骨格、会話の中止・参照・反応判断、部品の合成を対象とします。

開発環境では38件のテストとビルドの成功が記録されています。これは任意の身体や場面での自然さを保証するものではありません。会話内容や端末情報を含み得る実行記録・検証JSONは公開していません。

2026-09-20の公開用コピーでもビルドと全38件のテストが成功しました。実モデルのテスト時のみローカルの基準モデルを配置し、モデルがGitの除外対象で、コミットに含まれていないことを確認しました。
