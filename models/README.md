# 表示モデルの配置

モデル本体はこのリポジトリに含めていません。自身で利用条件を確認して取得したVRM 1.0モデルを `models/avatar.vrm` に配置してください。モデル、テクスチャ、モーションデータの権利は、それぞれの権利者に帰属します。リポジトリのMITライセンスはこれらの第三者データには適用されません。

現在の見本と実モデルを使うテストは AvatarSample_Y_VRM10 を基準に調整されています。他のモデルでは見た目やテスト結果が異なる場合があります。

- 基準モデルの作者：pixiv VRoid Project / yomox9
- 公式案内：[AvatarSample A〜Z](https://vroid.pixiv.help/hc/ja/articles/4402394424089-AvatarSample-A-Z)
- 基準ファイルのSHA-256：`25b05e3415bb35a787f2477728da9747111eff2388a8150c8ebf01cd193366b8`

動作表示と実モデルを使うテストにはモデルの配置が必要です。TypeScriptのビルドには必要ありません。取得済みモデルを誤って公開しないよう、VRMファイルはGitの除外対象にしています。
