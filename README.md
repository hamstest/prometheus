# Prometheus V3

キャラクターと対話するローカルアプリです。Emberテーマのチャットを主画面とし、身振りを作る補助モーションエディターを備えます。V1・V2の実行器やデータベースに依存しない新規実装です。

## 起動

Node.js 24以上を使います。

```powershell
cd prometheus
npm ci
npm start
```

起動前に、利用条件を確認して取得したVRM 1.0モデルを `models/avatar.vrm` に配置してください。[モデルの配置](models/README.md)を参照してください。モデル本体・会話履歴・第三者モーションデータセットは配布していません。

[アプリを開く](http://127.0.0.1:4319)。`npm start` はTypeScriptをビルドしてサーバーを起動します。初回に手付けの見本12件、構成例1件、基本操作26件を保存します。これらは操作例であり、人が採用した自然な動作・学習成果ではありません。

## Tailscaleから開く

必要な場合のみ、自分のTailscale環境でServeを設定し、`http://127.0.0.1:4319`へ転送します。`config/access.example.json`を`config/access.json`へコピーして、自分の正確なHTTPS originを`tailnetOrigins`に追加し、サーバーを再起動してください。個人用の接続先や設定はGit管理しません。設定ファイルがない場合はローカル接続だけを許可します。[Tailscale Serveの公式説明](https://tailscale.com/docs/reference/tailscale-cli/serve)。

## 対話と編集

[チャットを開く](http://127.0.0.1:4319)。インストール済みCodexのChatGPTログインを使います。Windowsではデスクトップアプリの同梱実行ファイルを優先し、なければPATH上のCLIを使用します。明示指定は `PROMETHEUS_CODEX_BIN`。未ログインなら「ログイン」でURLを発行し、ブラウザーで認証後「再接続」を押してください。APIキーへの自動切り替えはありません。

右側に入力しEnterで送信、Shift+Enterで改行。「中止」で生成を止められます。会話モデルは実際の利用可能一覧から選びます。履歴はSQLiteに保存され、左の履歴から再開できます。モデルには直近40件の完了メッセージを送ります。

まずエージェントが「文章だけ・表情・身体動作」を判断します。文章だけの会話では動作の検索・作成・再生や表情の変更をしません。身体動作が必要なら完成動作を検索し、見つからなければ既存の基本操作を調べて組み立てます。動作なしで「拍手しますね」と返して終わることは、身体動作が必要という判断と矛盾するためホストが作成を継続させます。対応範囲上作れなかった場合は実行していないことと理由を返します。

動作検索は関連する最大8件・3,600 UTF-8バイト以内のIDと説明だけです。構成と使用条件は要求後、曲線の数値はさらに必要な場合だけ開示します。「頭を下げる・戻すからうなずきを作り、それを二回組み合わせて」のように、基本操作から中間動作を作り、それを次の材料にできます。最終候補と必要な中間動作を保存・試演し、「この動きはイメージに合っていますか？」と確認を求めます。未採用の生成候補は再利用時にも候補として示します。「それを少しゆっくり」などの続きは会話で実際に試した固定版を参照できます。会話の「反応の判断・動作の作成記録」に判断と経路を残し、作成中も進捗を表示します。音声入力・読み上げは未実装です。

左の「モーション」で補助エディターへ切り替えます。見本を開くと下に関節角の時間曲線、上に対応する手先・頭の軌跡が表示されます。曲線の点は時刻と角度、3Dの点は選択中の1軸の角度をドラッグ編集できます。数値欄・矢印キーも使えます。「変更を戻す」で曲線変更を戻せます。自由なXYZ移動や全身IKではありません。

未保存案を切り替えた後は「前の編集案」で直前の案を復元できます。構成への追加は一覧の各行の「＋」から行います。

「身体・意味・部品の知識」では「基本操作」「組み合わせた動作」「表現・見本」で意味検索できます。順番または異なる部位の同時合成を行い、「組み立てて部品として保存」で中間動作を作ります。その全体や一部を次の材料にして繰り返し組み立てられます。構成のリンクから元の基本操作までたどれます。「編集案を作る」は通常の曲線エディターへ渡します。[知識と部品の使い方](docs/knowledge.md)を参照してください。

1. ライブラリから「挨拶から紹介へ」を選んで「試演」。手を上げた区間同士を直接つなぐ例です。正面・斜め・側面から確認できます。
2. 「新しい構成」を作り、一覧の「＋」で見本を追加。保存済み構成は元のクリップ固定参照を保ったまま区間列へ展開します。
3. 開始・終了時刻、速度、接続時間、順番を編集し「▶ 試演」。スライダーで静止確認し、「ライブへ」で実行中の表示へ戻ります。
4. 意味・場面・保存先IDを指定して「新版を保存」。一覧の選択で既存版を読み込みます。共有元の版は変わりません。
5. 人が実際の動きを確認した後、選択した保存版の「出典と採用の記録」にメモと判定を残せます。版・身体・場面ごとの記録であり、保存しただけで採用にはなりません。

編集中の案はメモリ内に保持します。ページを再読込する前に候補として保存するか、JSONを書き出してください。

独自の見本は「モーションJSON」から読み込み、「編集案へ反映」で検証できます。[見本JSON](examples/nod.clip.json)と[登録リクエスト](examples/register.json)を同梱しています。動作名に対応するコードの追加は不要です。任意のBVH・動画・VRMAを直接読み込む機能は含みません。

## エージェントから使う

サーバーを起動した状態で、別のターミナルから操作できます。

```powershell
npm run motion -- search 相手に挨拶する
npm run motion -- inspect greeting 1
npm run motion -- execute greet-and-present 1
npm run motion -- state
npm run motion -- save examples/register.json
```

外部MCPホスト用の設定例：

```json
{
  "mcpServers": {
    "prometheus-v3": {
      "command": "node",
      "args": ["/absolute/path/to/prometheus/src/mcp.ts"]
    }
  }
}
```

`motion_ontology → motion_knowledge-search → motion_knowledge-inspect → motion_derive → motion_play → motion_save` が意味と部品を使う制作経路です。従来の `inspect / validate / edit` も使用できます。ローカル実行器がフレームを生成します。ツールの詳細は [操作API](docs/api.md) を参照してください。

## 設計の中心

「前腕を右回りに30度ひねる」などを、意味付き操作＋角度・時間／平均速度で作成・編集できます。前腕／上腕のひねり、肘の曲げ伸ばし、頭の左右／上下、体幹のひねりの6操作を用意しました。モーションの「身体・意味・部品の知識」内から利用でき、会話エージェントも必要な操作定義だけを検索・取得して生成します。生成結果は上位の動作へ再利用できます。[意味付き操作の使い方](docs/semantic-operations.md)。

- 見本は関節の位置・速度・加速度を持つ曲線、構成は見本の固定版を指す時間区間列。保存・編集・再生で同じ形式を使います。
- 途中切り替えは現在の位置・速度・加速度から、指定区間の入口へ接続します。入口側の終速・加速度も保ちます。全見本を指定した場合、見本内に書かれた準備・回収はそのまま再生します。
- 同じ曲線の隣接区間を元の順に戻す場合、余分な接続を挿入しません。速度変更時は速度・加速度も時間倍率に合わせます。
- 曲線の途中を含む座標範囲を検査し、成立しない接続は現在の実行を置き換える前に拒否します。数値上の範囲検査は、衝突回避や自然さの保証ではありません。
- 保存版は不変。編集中に別の保存が進んだ場合は競合を通知し、古い編集による上書きを防ぎます。

前提の採否と代案は [設計判断](docs/design.md)、確認結果と対応範囲は [検証記録](docs/verification.md) に記載しています。

## 対応範囲

基準モデルAvatarSample_Y_VRM10の固定立位・上半身。モデルは別途取得・配置が必要です。正規化VRM骨格の局所XYZ Euler角、単位はrad・秒です。未指定のチャンネルは既定の休息値になります。下半身と身体寸法はモデルのまま保持します。

意味検索は版付きの概念辞書・別名・上位関係・部位・区間定義を使います。異なる部位の同時合成は、所有の競合と長さを検査して通常のクリップへ変換します。未知動画からの自動分解、任意対象への指差し、歩行、任意体型への適応、自己衝突検査、学習による接続改善は未実装です。意味と自然さの適切さは別途評価します。

## 保存・検証

- `data/library.sqlite`：モーションの固定版と条件付き評価。再起動後も保持。
- `models/avatar.vrm`：利用者が別途配置する表示身体。Git管理対象外。[モデル情報](models/README.md)。
- `PORT`：既定4319。`PROMETHEUS_V3_DB`：DBの保存先。`PROMETHEUS_V3_URL`：CLI/MCPの接続先（loopback HTTPのみ）。

## 表情・動作の追加と手の向き（2026-09-09）

表情は「自然・笑顔・やわらかい笑み・驚き・悲しみ・怒り」。キャラクター上の「表情」で種類と強さを選び、6秒間試せます。自然なまばたきも切り替え可能です。会話ではモデルが文脈に合わせて表情を選び、動作と一緒に再生します。表情は短く保持した後に自然へ戻り、会話履歴から再び試せます。

新しい見本は「左手で挨拶」「左側を手で示す」「軽くお辞儀する」「やさしく首を横に振る」「考えるように首をかしげる」「ゆっくり相づちを打つ」「両手を開いて迎える」「両手を上げて驚く」の8種類。見本は計12種類になりました。

挨拶と紹介の既存見本では、手のひらが斜め下／下を向いていました。肩・肘・手首の回転を修正し、挨拶は相手へ、紹介は上へ向けています。「手のひらの向き」の矢印と「上半身」カメラで確認できます。左右はキャラクター自身を基準とし、正面ではキャラクターの右は画面左です。

既存DBでは未編集の同梱見本を新版として追加します。過去の固定版と評価は変えません。会話履歴の再生ボタンは、その会話で使った版を表示して再生します。通常の新しい会話や一覧では最新版が使われます。編集済みの見本は起動時に自動上書きしません。
